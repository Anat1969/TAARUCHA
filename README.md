# תערוכות — ענת דוד שטיבלמן

פלטפורמה ציבורית לפרסום תערוכות: קולקציות של דימוי, טקסט ווידאו, עם סטודיו לעריכה והעלאה.

## מבנה

- `/` דף בית: התערוכה הנוכחית וכל התערוכות
- `/e/:slug` דף תערוכה: הליכה אופקית לאורך קיר מואר (בנייד: רצף אנכי), תצוגה מוגדלת לכל עבודה
- `/archive` כל העבודות, עם סינון לפי מדיה
- `/about` אודות
- `/studio` סטודיו: כניסה, יצירה ועריכה של תערוכות, העלאת תמונות ווידאו, סידור ופרסום

## טכנולוגיה

- Vite + React, framer-motion להנפשות
- Supabase (פרויקט cultura-GH): טבלאות `taarucha_exhibitions`, `taarucha_works`, `taarucha_settings`, `taarucha_admins`, ודלי `taarucha-media`
- הרשאות: קריאה ציבורית לתערוכות שפורסמו בלבד; כתיבה רק למשתמשים בטבלת `taarucha_admins`
- פריסה: Vercel

## פיתוח מקומי

```
npm install
npm run dev
```

אפשר להגדיר `VITE_SUPABASE_URL` ו־`VITE_SUPABASE_PUBLISHABLE_KEY`. ברירת המחדל בקוד היא המפתח הציבורי של הפרויקט.
